# Tales design — premium dark

Philosophy: Omnipair beta + tokens.xyz — quiet chrome, high contrast type, no neon.

| Role | Value |
|------|--------|
| Page | `#0a0a0a` |
| Elevated | `#141414` |
| Primary CTA | `#f4f4f5` on `#0a0a0a` |
| Text | white / white 40–50% muted |
| Borders | `white / 8–10%` |
| Long / buy | emerald (semantic only) |
| Short / sell | red (semantic only) |

**Do not use** lime/chartreuse accent pills or neon status labels.

Graduated markets: Omnipair mark on the card image (not a “LIVE” badge).
Bonding: thin white progress bar only.
Typography: Geist, medium weights, tight tracking on titles, `tabular-nums` for figures.
